# Maniskanda D K — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` in your browser.
3. For the best development experience, use the VS Code Live Server extension.

## Before publishing

Replace:
- `your.email@example.com` with your real email.
- LinkedIn URL with your LinkedIn profile.
- Add your resume PDF and link it from the Resume section if needed.
- Add project GitHub links to the project cards.

## Deploy

The site can be hosted using GitHub Pages, Netlify or Vercel.
